## 고친 것

- **없는 주소가 Next.js 기본 영어 화면("404 This page could not be found.")으로 떴다.**
  `src/app/not-found.tsx`를 만들어 "없는 페이지예요" + "처음 화면으로 가기"로 바꿨다. 상태 코드 404 유지

## 알고 넘어가는 것

1. **없는 트럭 링크(`/t/no-such-truck`)가 404가 아니라 200으로 응답한다.** 화면과 카톡 미리보기는 "트럭을 찾을 수 없어요"로 맞게 나온다.
   검색엔진에만 영향이 있어서 MVP에서는 두었다
2. **위치 정하기 `?mock=empty`에 "오늘 영업 정보를 불러오지 못해…" 문구가 같이 뜬다.** `?mock=empty`가 장소 목록과 오늘 세션을 둘 다 비워서다.
   시험용 주소에서만 생기는 일이라 두었다
3. **`/nearby`는 "준비 중" 임시 화면이다.** 화면에 링크는 없지만 주소를 치면 열린다. 11/8 `/dev`를 지울 때 같이 정한다
4. **영업시간 없이 오픈된다.** `product-rules.md` `[미정]` — 11/9 회의에서 정한다
