## 범위 조정

**화면은 줄이지 않는다.** 남은 프레임 17장과 피그마에 없는 2장을 전부 목데이터로 만든다.

**백엔드에 막힌 두 가지만 대체한다**

- 실제 API 연동 → **목데이터 버전으로 제출한다.** 연결할 서버 코드가 없다.
  목데이터 함수를 `src/lib/mock/` 한 곳에 모아 뒀으니, API가 오면 그 안쪽만 바꾸면 된다
- 소셜 로그인 → **목 로그인으로 대체한다.** 받은 `code`를 넘길 `POST /api/v1/auth/social`이 없다.
  로딩 · 취소 · 실패 화면은 만든다

**꼭 지킬 것:** 배포, `/t/:slug`의 카카오톡 미리보기(OG)

**디자인 작업을 줄일 수 있는 곳:** 손님 `02 트럭 상세 시트`에 공유 페이지에 필요한 내용
(영업 상태, 위치, 영업시간, 메뉴, 비활성 알림 버튼)이 이미 다 있다. 이 시트를 한 장짜리 페이지로 펼쳐 `/t/:slug`로 쓴다.
새로 그려야 하는 건 "오늘은 쉬어요" 한 장이다.
