# 디자인 시스템

## 대원칙

1. **색·간격·글자 크기를 코드에 직접 쓰지 마라.** 반드시 토큰(CSS 변수)을 쓴다.
   - 금지: `color: #ff6b35`, `padding: 13px`, `font-size: 15px`
   - 허용: `color: var(--text-brand)`, `padding: var(--space-3)`
2. **토큰에 없는 값이 필요하면 만들지 말고 물어봐라.** 새 색을 추가하는 건 디자인 결정이다.
3. **다크 모드를 구현하지 마라.** 앱인토스 미니앱은 다크 모드를 지원하지 않는다. 라이트 모드 단일 기준이다.
4. 토큰 이름은 피그마 변수 이름과 1:1로 일치시킨다. 피그마 `brand/primary` → CSS `--brand-primary`.

## TDS 전환을 염두에 둔 구조

나중에 토스 디자인 시스템(TDS)으로 갈아탈 가능성이 있다. 그래서 **원시값과 의미값을 분리한다.**

```
원시(primitive)   --orange-500: #ff6b35     ← 실제 색값. 여기만 바뀐다
의미(semantic)    --brand-primary: var(--orange-500)   ← 컴포넌트는 이것만 쓴다
```

컴포넌트 코드는 **의미 토큰만** 참조한다. 그래야 TDS로 옮길 때 의미 토큰의 우변만 갈아끼우면 끝난다.

**TDS 토큰 이름을 추측해서 쓰지 마라.** 실제 이름은 앱인토스 개발자센터의 디자인 가이드를 보고 확인한 뒤에 매핑한다. 지금은 위 구조만 지킨다.

## 색상 토큰

피그마 파일의 하드코딩된 색 31종을 아래 15종으로 통합한다. **목록에 없는 색은 쓰지 않는다.**

### 브랜드

| 토큰 | 값 | 용도 |
|---|---|---|
| `--brand-primary` | `#ff6b35` | 주 버튼 배경, 강조 요소 |
| `--brand-primary-subtle` | `#fff4ed` | 연한 배경, 선택 상태 |
| `--brand-primary-text` | `#c2410c` | **주황색 글자가 필요할 때만** 이걸 쓴다 |

> `#ff6b35`를 글자색으로 쓰면 흰 배경 대비 2.8:1로 접근성 기준(4.5:1) 미달이다.
> 주황은 배경으로만 쓰고 그 위에 흰 글씨를 올린다. 글자를 주황으로 해야 하면 `--brand-primary-text`.

### 텍스트

| 토큰 | 값 | 용도 |
|---|---|---|
| `--text-default` | `#1a1a1a` | 본문, 제목. 순수 검정(`#000`)은 쓰지 않는다 |
| `--text-secondary` | `#555555` | 보조 설명 |
| `--text-muted` | `#666666` | 흐린 라벨. 기존 `#888888`은 대비 미달이라 상향 조정됨 |
| `--text-on-brand` | `#ffffff` | 주황 배경 위 글자 |

### 배경 · 선

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg-surface` | `#ffffff` | 카드, 시트, 모달 배경 |
| `--bg-page` | `#f5f5f5` | 페이지 배경 |
| `--border-default` | `#e0e0e0` | 구분선, 카드 테두리 |
| `--border-strong` | `#cccccc` | 입력창 기본 테두리 |
| `--border-focus` | `#c2410c` | 입력창 포커스 테두리 · 포커스 링 |

#### 입력창 테두리를 진하게 하지 않는 이유 — 2026-09-08 판단

`--border-strong` `#cccccc`는 흰 배경 대비 **1.6:1**이다. WCAG 1.4.11(비텍스트 대비)이 요구하는 3:1에 미달한다.
그런데 **테두리를 진하게 올리지 않는다.** TDS를 비롯한 국내 모바일 UI는 입력창을 진한 선으로 두르지 않고, 면(fill)과 여백으로 구분하는 방향이기 때문이다. 선을 `#949494`까지 올리면 3:1은 넘기지만 화면이 무거워지고 나중에 TDS로 옮길 때 다시 걷어내야 한다.

대신 **아래 세 가지를 지켜서 접근성을 확보한다.** 1.4.11은 테두리가 컨트롤을 식별하는 *유일한* 수단일 때 3:1을 요구하므로, 다른 식별 수단이 있으면 충족된다.

1. **입력창은 반드시 배경색으로 구분한다.** 페이지 배경이 `--bg-page`면 입력창은 `--bg-surface`, 카드 위(`--bg-surface`)에 놓이면 입력창은 `--bg-page`. 면이 다르면 테두리가 없어도 컨트롤임을 안다.
2. **라벨을 반드시 붙인다.** placeholder만으로 대체하지 마라. 입력하면 사라져서 무슨 칸인지 알 수 없게 된다.
3. **포커스는 `--border-focus`로 2px.** `#c2410c`는 흰 배경 대비 **5.18:1**이라 충분하다.
   `--brand-primary` `#ff6b35`를 포커스 링에 쓰지 마라. 흰 배경 대비 **2.8:1**로 3:1에 미달한다.

## 타이포그래피

본문 서체는 **주아체**. **Regular 한 가지 굵기뿐이다.**

- `font-weight: bold` 를 쓰지 마라. 렌더링이 깨지거나 가짜 굵기(faux bold)가 적용된다.
- 위계는 **크기와 색으로만** 만든다.

| 토큰 | 크기 / 행간 | 용도 |
|---|---|---|
| `--font-display` | 28 / 36 | 화면 대표 제목 |
| `--font-title` | 22 / 30 | 섹션 제목 |
| `--font-subtitle` | 18 / 26 | 카드 제목, 메뉴명 |
| `--font-body` | 16 / 24 | 본문 |
| `--font-caption` | 14 / 20 | 보조 설명 |
| `--font-label` | 12 / 16 | 배지, 라벨 |

## 컴포넌트

아래 5개는 피그마 컴포넌트와 이름·variant가 일치해야 한다. **같은 역할의 UI를 새로 만들지 말고 이걸 재사용하라.**

| 컴포넌트 | variant | state |
|---|---|---|
| `Button` | `primary` `secondary` `kakao` `google` | `default` `pressed` `disabled` `loading` |
| `BottomNav` | — (사장님 전용) | 선택된 탭: `home` `location` `menu` |
| `MenuCard` | — | `available` `soldout` |
| `TextInput` | — | `default` `focus` `error` |
| `Toggle` | — | `on` `off` `disabled` |

**`BottomNav`는 사장님 화면에만 쓴다. (확정 — 2026-09-16)**
원래 `owner` `customer` 두 variant였지만 손님 화면은 하단 탭 없이 지도 + 시트 구조로 가므로 `customer`를 없앴다.
탭은 **사장님 홈 · 위치 정하기 · 메뉴 정하기** 3개다.

- "손님 보기"는 탭이 아니다. 홈 화면의 **"내 가게 페이지 미리보기"** 버튼으로 바꾼다.
  다른 트럭까지 보이는 주변 지도(`/nearby`)가 아니라 **내 트럭의 공유 링크 페이지(`/t/:slug`)만** 연다.
  손님에게 링크를 보내기 전에 위치·메뉴가 제대로 보이는지 확인하는 용도다
- 설정·로그아웃은 탭이 아니다. 자주 누르지 않으므로 홈 상단 아이콘으로 둔다
- 피그마 프레임에는 아직 4탭(손님 보기 포함)으로 그려져 있다. 코드가 기준이고 피그마는 나중에 맞춘다

## 레이아웃

- 기준 폭 393px, **최소 지원 폭 360px.** 360px에서 깨지지 않아야 한다.
- 텍스트가 길어지면 밀리지 않도록 flex 기반으로 짠다. 고정 폭·고정 높이를 쓰지 마라.
- 메뉴명은 **15자 이상**으로 테스트한다. "매콤 크림치즈 타코야끼 세트" 같은 이름이 실제로 들어온다.
- 웹뷰 환경이므로 상·하단 안전영역을 `env(safe-area-inset-*)`로 처리한다.

## 접근성

- 텍스트 대비 4.5:1 이상. **야외 햇빛 아래에서 쓰는 앱이라 특히 중요하다.**
- 터치 영역 최소 44×44px.
- 상태를 색으로만 표현하지 마라. "영업 중 / 준비 중"은 색 + 글자를 함께 쓴다.
