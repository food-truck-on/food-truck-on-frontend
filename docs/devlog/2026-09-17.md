## 판단

### 품절 토글을 눌러도 성공 토스트를 띄우지 않기로 했다

처음에는 품절로 바꾸면 카드에 "품절" 배지가 붙고, 토글 글자가 바뀌고, 아래에 토스트까지 떴다.
한 번 누른 일에 세 군데가 동시에 바뀌니 정신이 없었다.
토글은 바뀐 상태를 계속 보여주므로 결과를 따로 알릴 필요가 없다. 성공 토스트를 빼고,
카드에 변화가 안 보이는 **실패**일 때만 토스트로 원인과 해결책을 알리게 했다.

### 토글 스위치를 항상 오른쪽 끝에 두었다

상태 글자가 "품절"(2자)과 "판매 중"(3자)으로 길이가 달라서, 카드마다 스위치 위치가 좌우로 어긋났다.
`<button>`이 내용 폭만큼만 넓어지는 게 원인이라 `Toggle`이 부모 폭을 채우게 했다.
공통 컴포넌트에서 고쳤으므로 다른 화면의 토글도 같은 위치에 선다.

## 알게 된 것

- 타입은 "메뉴에는 id · 이름 · 가격이 있다"는 틀이고, 목데이터는 그 틀에 채운 값이다.
  `Menu` 타입을 먼저 채워야 `menus.ts`에 칸을 빼먹거나 이름을 틀렸을 때 에디터가 빨간 줄로 알려준다.
- 토글은 상태를 보여주고, 버튼은 동작을 실행한다. 켜짐/꺼짐이 계속 유지되는 품절은 토글,
  한 번 하고 끝나거나 되돌리기 어려운 마감은 버튼 + 확인 다이얼로그로 간다.
- JavaScript 키는 코드가 쓰는 출입증이고, 콘솔의 도메인 등록은 그 키를 쓸 수 있는 주소 목록이다.
  키는 `.env.local`에만 두어 커밋되지 않게 했고, 지도 코드를 짜는 날 막히지 않게 발급을 먼저 끝냈다.
