## 판단

### 아이콘 색을 SVG 파일이 아니라 토큰으로 정하게 했다

피그마에서 내보낸 SVG에는 `#ff6b35` 같은 색이 박혀 있다. 그대로 쓰면 색을 바꿀 때마다 파일을 다시 내보내야 하고,
나중에 TDS로 옮길 때 의미 토큰만 갈아끼워도 아이콘은 안 바뀐다.
그래서 모양만 가면(mask)으로 뜨고 `background: currentColor`로 칠했다. 아이콘 색이 부모의 글자색을 따라가서 색 규칙이 한 곳으로 모인다.

### 별을 선택 표시가 아니라 "맨 위 고정"으로 바꿨다

피그마 `03`에서는 고른 장소의 별이 주황으로 켜진다. 즉 별이 선택 표시였다.
그런데 명세에는 즐겨찾기 칸이 따로 없고 **자주 가는 장소 목록 자체가 즐겨찾기**다(3-1 조회 · 3-2 추가 · 3-3 삭제).
별이 선택 표시면 목록에서 별이 하는 일이 없어진다. 그래서 별은 **목록 맨 위 고정**으로, 선택은 테두리와 체크 표시로 갈랐다.
고정 상태를 저장할 칸이 서버에 없어서 목데이터에 `is_favorite`를 먼저 넣고 백엔드에 요청을 걸었다.

### 고정을 풀어도 원래 자리로 되돌리지 않는다

처음에는 고정을 풀면 원래 순서로 돌아가게 만들었다. 그러면 방금 누른 항목이 목록 아래로 멀리 튄다.
지금은 남은 고정 장소 바로 아래에 둔다. 손가락이 있던 자리 근처에 머물러서 목록이 덜 튄다.

### 고르기와 저장을 나눴다

피그마 버튼은 "현재 위치로 설정"인데 누른다고 저장되지는 않는다. 아래 "이 위치로 설정"을 눌러야 저장된다.
문구대로면 두 번 저장하는 것처럼 읽혀서 "현재 위치 불러오기"로 바꿨다.
잘못 누른 장소가 바로 손님 화면에 나가면 안 되므로 저장은 한 번 더 누르게 두는 쪽을 택했다.

### 지도가 안 떠도 화면이 동작하게 만들었다

카카오맵은 개발자 콘솔에 등록된 도메인에서만 뜬다. 배포 주소를 등록하기 전에는 지도가 안 뜬다.
지도가 실패하면 그 자리에 안내를 띄우고, 목록에서 고르면 그대로 저장되게 했다. 지도 하나 때문에 위치를 못 정하면 안 된다.

## 알게 된 것

- **스테이징은 커밋에 넣을 파일을 골라 담는 대기실이다.** 작업 폴더 → `git add` → 스테이징 → `git commit` 순서다.
  파일을 고치기만 해서는 커밋 대상이 아니다. 오늘처럼 화면·문서·설정을 섞어 작업해도 나눠서 커밋할 수 있는 게 이 단계 덕분이다.
- **`git status`는 앞 칸을 봐야 한다.** 앞 칸이 비어 있으면(` M`) 아직 담기지 않은 것이고, `??`는 git이 추적조차 안 하는 새 파일이다.
- 작업을 끝냈다고 보고하기 전에 `npm run lint` · 타입 검사 · 프로덕션 빌드 세 가지를 돌린다.
  빌드까지 돌리는 이유는 지도 SDK처럼 브라우저 전용 코드가 서버 렌더링에서 터지는 걸 개발 서버에서는 못 잡기 때문이다.
